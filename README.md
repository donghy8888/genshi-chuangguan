# 初中数学闯关学习

给初中同学使用的数学练习网站：包含二次根式闯关，以及独立的一元二次方程循序渐进课程。

## 一元二次方程新章节\n\n首页进入「一元二次方程 · 新章节」，按顺序学习 8 个小关卡：认识标准形式、开平方、因式分解、配方法、求根公式、判别式、选择解法、应用题。每关先看讲解和例题，再做 3 道题；答对至少 2 道即可解锁下一关。进度保存在当前浏览器中。\n\n## 怎么玩

1. 下载 [`index.html`](./index.html)
2. 用手机或电脑浏览器直接打开（不用联网）
3. 首页点「开始今日挑战」或「导入试卷」

进度保存在浏览器本地，请尽量用同一个浏览器打开，不要清除网站数据。

## 功能

- 8 关 + Boss 关（热身开方 → 有意义条件 → √(a²)=|a| → 化简 → 最简 → 同类 → 加减 → 乘除/有理化）
- 每日打卡、连胜火苗、XP 与徽章
- 错题间隔复习（连续答对 3 次才算掌握）
- 每关课前小课堂：公式 + 例题步骤 + 口诀
- 导入试卷：拍照/相册，勾选不会的知识点后开练

## 开发

可编辑源码在 `src/`，运行 `sh src/build.sh` 会重新生成 `index.html`。
