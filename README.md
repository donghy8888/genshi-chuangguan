# 二次根式闯关

给初中八年级同学用的二次根式练习小游戏：闯关、每日打卡、错题复习、课前讲公式，还可以导入试卷照片对照知识点练习。

## 怎么玩

1. 下载 [`index.html`](./index.html)
2. 用手机或电脑浏览器直接打开（不用联网）
3. 首页点「开始今日挑战」或「导入试卷」

进度保存在浏览器本地，请尽量用同一个浏览器打开，不要清除网站数据。

## 功能

- 8 关 + Boss 关（热身开方 → 有意义条件 → √(a²)=|a| → 化简 → 最简 → 同类 → 加减 → 乘除/有理化）
- 每日打卡、连胜火苗、XP 与徽章
- 错题间隔复习（连续答对 3 次才算掌握）
- 每关课前小课堂：公式 + 例题步骤 + 口诀
- 导入试卷：拍照/相册，勾选不会的知识点后开练

## 开发

可编辑源码在 `src/`，运行 `sh src/build.sh` 会重新生成 `index.html`。
